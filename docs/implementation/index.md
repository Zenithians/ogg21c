# Implementasi OGG

Bagian implementasi berisi panduan teknis berdasarkan versi Oracle GoldenGate dan pasangan database.

## Struktur

```text
implementation/
  19/
    sqlserver-to-sqlserver/
  21/
    oracle-to-oracle/
```

Saat ada skenario baru, tambahkan subfolder sesuai versi dan jenis database, misalnya:

```text
implementation/
  21/
    postgresql-to-oracle/
  23/
    mysql-to-oracle/
```
